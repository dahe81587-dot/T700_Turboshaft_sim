使用入口
========
在 T700_Dyn / While Iterator Subsystem 中双击 Plot Outputs。
无需打开数据检查器；已有 8 组运行已提取为独立轨迹存档。

图窗
====
分别打开压气机、燃气发生器涡轮 GGT、动力涡轮 FPT 三张图。
每张左图为 WcMap-PRMap 特性图，右图为效率特性图。
彩色线是运行轨迹，空心圆为起点，实心方块为终点。
无扰动运行使用点线，负扰动使用虚线，其他运行使用实线。
选择运行结果：选择本张图需要叠加的记录，例如燃油 +1% 与 -1%。
放大轨迹范围：放大当前可见轨迹。恢复全图：恢复完整特性范围。
点击图例可同时隐藏或显示本张图两个坐标轴上的对应轨迹。

后续运行
========
仿真完成后双击按钮，将现有运行日志及工作区 CompData/GGTData/FPTData 中的新轨迹加入存档。
相同数据重复点击不会重复归档。若仅用工作区日志，每次运行后点击一次，避免下一次运行覆盖旧日志。
原有存档中的运行名称按保存时名称显示，未命名的 Run 5 不作工况推断。

数据与坐标
==========
独立轨迹存档：results/component_maps/T700_map_history.mat。
底图使用 MWS 内实际 Map 参数，轨迹使用相同坐标系中的 WcMap/PRMap/EffMap。
压气机调用 TMATS.PlotCMap，涡轮调用 TMATS.PlotTMap；恒定流量表做显示兼容处理。
当前涡轮表的转速行重合，不人为生成独立转速线或二维效率等值线。
地图参数发生变化时拒绝将旧轨迹叠加到不匹配的新地图。
已打开模型的旧 PlotSSData 回调通过兼容脚本接入新入口；磁盘模型直接调用新函数。
